⚡ Arquitetura do Motor Ollama

A AlEx Platform v2 é projetada para utilizar qualquer instância do Ollama instalada localmente ou em servidores remotos/nuvem.

Endpoint Ativo: OLLAMA_URL (padrão: http://localhost:11434)
Modelo Padrão: qwen2.5-coder:7b
Agentes Conectados: Alex, Alia e Agentes Customizados

💡 Dica: Para alterar o servidor Ollama, basta definir a variável de ambiente OLLAMA_URL ao iniciar a aplicação.
