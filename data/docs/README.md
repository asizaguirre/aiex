# AlEx AI Platform v3

Enterprise AI Agent Platform.

## Stack

- Java 21
- Spring Boot 3.5
- Spring Boot static frontend
- Ollama
- Docker

## Architecture

Multi-agent AI platform with RAG and memory.

## Status

Under development.

## Como iniciar

1. Copie e ajuste as variáveis em `.env.example` para `.env`.
2. Execute `./alex.sh` para construir e iniciar a plataforma em Docker.
3. Use `./alex.sh --local` para executar Java e Ollama diretamente no sistema.
