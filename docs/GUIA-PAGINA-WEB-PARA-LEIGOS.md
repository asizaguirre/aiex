# 🌟 Guia Passo a Passo: Crie Sua Página Web sem Saber Programar

Este guia foi feito para **quem nunca mexeu com internet além de redes sociais**.
Sem palavras difíceis, sem instalar nada de estranho. Só você, seu navegador e um tempinho.

---

## 📖 Primeiro: o que é uma "página web"?

Pense numa **vitrine de loja**, mas na internet:

```
   VOCÊ (dono do negócio)                SEU CLIENTE
          │                                   │
          │  monta a vitrine                  │  recebe o link
          ▼                                   ▼
   ┌──────────────────┐    internet     ┌──────────────────┐
   │   PÁGINA WEB     │ ◄─────────────► │  Celular ou      │
   │  (sua vitrine    │    (o link)     │  computador do   │
   │   digital)       │                 │  cliente         │
   └──────────────────┘                 └──────────────────┘
```

- **Você** monta a vitrine uma vez (com fotos, textos e preços).
- **Seu cliente** entra pelo link (ex.: `meupagina.site/meubolo`) e vê tudo bonitinho.
- O link você espalha no **WhatsApp, Instagram, Facebook**... onde quiser!

---

## 🎒 O que você precisa antes de começar

Marque as caixinhas conforme conseguir:

- [ ] Um **computador ou celular** com internet
- [ ] Um **navegador** (Chrome, Edge, Firefox... aquele programa que você usa pra entrar em sites)
- [ ] Um **e-mail** (pra criar contas grátis)
- [ ] **Fotos do seu produto/negócio** no aparelho (se ainda não tem, tire com o celular!)
- [ ] De **30 minutos a 1 hora** de tempo tranquilo ☕

---

## 🛠️ Qual ferramenta escolher?

Todas são **gratuitas** e funcionam direto no navegador (nada de instalar programa):

| Ferramenta | Melhor para... | Facilidade | Custo |
|------------|----------------|------------|-------|
| **Carrd** 🥇 | Página de vendas bonita, de uma tela só | Muito fácil | Grátis |

> Se quiser algo mais simples ainda (só texto e links), use o **Notion**.

# PARTE 1 🎨 — Prepare suas imagens no Canva

O Canva é como um **Paint moderno e fácil**, com modelos prontos.

### Passo 1.1 — Entre no Canva
1. Abra o navegador e digite: **`www.canva.com`**
2. Clique em **"Cadastre-se gratuitamente"** (pode usar sua conta do Google pra facilitar).
3. Vai aparecer uma tela assim:

```
 ┌─────────────────────────────────────────────┐
 │  Canva                                      │
 │                                             │
 │  O que você vai criar hoje?                 │
 │                                             │
 │  ┌─────────┐ ┌─────────┐ ┌─────────┐        │
 │  │ Post    │ │ Logo    │ │ Banner  │  ...   │
 │  └─────────┘ └─────────┘ └─────────┘        │
 └─────────────────────────────────────────────┘
```

### Passo 1.2 — Crie uma imagem de capa
1. Na barra de busca, escreva **"banner loja"** e aperte Enter.
2. Escolha um modelo que você gostou (clique nele).
3. **Troque os textos**: clique em cima do texto do modelo e digite o seu
   (ex.: *"Bolos da Maria — Feitos com amor"*).
4. **Troque as cores**: clique no elemento e use a paleta no canto superior.
5. Baixe a imagem: botão **"Compartilhar"** (canto superior direito) → **"Baixar"** → **"Baixar"** de novo.
   - A imagem vai para sua pasta de downloads. Guarde-a! 📁

### Passo 1.3 — Prepare fotos dos produtos
1. No Canva, clique em **"Criar design"** → **"Post para Instagram"** (tamanho quadrado, ótimo pra web).
2. Clique em **"Enviar"** (no menu lateral esquerdo) → **"Enviar arquivos"** → escolha a foto do seu produto.
3. Se quiser, adicione uma borda ou texto por cima.
4. Baixe igual ao passo anterior.

> ✅ **Meta desta parte:** ter salvo 1 imagem de capa + 1 a 3 fotos de produto.

# PARTE 2 🏗️ — Monte a página no Carrd (o passo principal)

O Carrd monta páginas de **uma tela só**, lindas e rápidas — perfeitas pra vender.

### Passo 2.1 — Crie sua conta
1. No navegador, digite: **`carrd.co`**
2. Clique em **"Sign Up Free"** (cadastrar grátis).
3. Use seu e-mail e crie uma senha. Pronto!

### Passo 2.2 — Escolha um modelo pronto
1. No painel, clique em **"+ Create a new site"** (criar novo site).
2. Vão aparecer vários modelos. Passe o mouse e clique em **um que tenha cara de loja/vendas**.
3. Escolha **"Standard (Free)"** quando perguntar do plano.

```
 ┌──────────────────────────────────────────────┐
 │  Escolha um modelo:                          │
 │                                              │
 │  ┌────────┐  ┌────────┐  ┌────────┐          │
 │  │ modelo │  │ modelo │  │ modelo │          │
 │  │   A    │  │   B    │  │   C    │          │
 │  └────────┘  └────────┘  └────────┘          │
 │   (clique no que mais gostar!)               │
 └──────────────────────────────────────────────┘
```

### Passo 2.3 — Edite os textos (é só clicar e digitar!)

A tela do editor fica assim:

```
 ┌────────────────────────────────────────────────────┐
 │  ← Voltar   [Seu modelo aparecendo aqui]   Salvar  │
 │                                                    │
 │   ┌──────────────────────────────┐                 │
 │   │  TÍTULO GRANDE  ← clique aqui│                 │
 │   │  e digite o seu!             │                 │
 │   └──────────────────────────────┘                 │
 │                                                    │
 │   ┌──────────────────────────────┐                 │
 │   │  Texto menor... ← idem!      │                 │
 │   └──────────────────────────────┘                 │
 └────────────────────────────────────────────────────┘
```

**O que escrever em cada parte (receita de bolo 🎂):**

| Parte da página | O que escrever | Exemplo |
|-----------------|----------------|---------|
| **Título grande** | O que você vende, com impacto | "Bolos Artesanais da Maria" |
| **Texto abaixo** | Uma frase que desperte desejo | "Bolos fresquinhos, feitos no dia, entregues na sua casa." |
| **Seção de fotos** | Suas fotos do Canva | (troque a imagem do modelo) |
| **Lista de destaques** | 3 motivos pra comprar de você | "✅ Ingredientes selecionados ✅ Entrega rápida ✅ Preço justo" |
| **Botão final** | O que o cliente deve fazer | "Pedir pelo WhatsApp" |

### Passo 2.4 — Troque as imagens
1. Clique na **imagem** do modelo.
2. No painel que abre, clique em **"Replace Image"** (trocar imagem) → **"Upload"**.
3. Escolha a imagem que você fez no Canva.

### Passo 2.5 — Coloque o botão do WhatsApp
1. Clique no **botão** do modelo.
2. No campo **"Link"**, cole este endereço (troque pelo SEU número, com 55 + DDD):

```
https://wa.me/5511999999999?text=Ola!%20Quero%20fazer%20um%20pedido
```

> 💡 Esse link mágico abre a conversa do WhatsApp do cliente **já com a mensagem escrita**!

### Passo 2.6 — Publique! 🚀
1. Clique em **"Publish"** (publicar), no canto superior direito.
2. No campo de endereço, escolha um nome: ex.: `bolosdamaria.carrd.co`
3. Clique em **"Publish Changes..."** e confirme.
4. **Pronto!** O site te mostra o link da sua página. 🎉

```
 ┌────────────────────────────────────┐
 │  ✅ Seu site está no ar!           │
 │                                    │
 │  🌐 bolosdamaria.carrd.co          │
 │                                    │
 │  [Copiar Link]  [Abrir]            │
 └────────────────────────────────────┘
```

# PARTE 3 📝 — Alternativa: página no Notion (mais simples ainda)

Se o Carrd parecer complicado, o Notion é como **escrever um documento bonito** e apertar "publicar".

### Passo 3.1 — Crie a página
1. Entre em **`www.notion.so`** e crie conta grátis.
2. Clique em **"+ New Page"** (nova página), no menu lateral.
3. Dê um título: ex.: *"Bolos da Maria"*.

### Passo 3.2 — Escreva sua vitrine
Dentro da página, digite e use os recursos da barra que aparece:

- Digite `/imagem` → envie sua foto do Canva.
- Digite `/botão` → crie um botão com link do WhatsApp (igual ao passo 2.5).
- Digite `/colunas` → organize fotos lado a lado.
- Use **listas** para os destaques (✅ ✅ ✅).

```
 ┌──────────────────────────────┐
 │  Bolos da Maria              │
 │  ─────────────────           │
 │  [foto do bolo]              │
 │                              │
 │  ✅ Feitos no dia            │
 │  ✅ Entrega grátis           │
 │                              │
 │  [  Pedir no WhatsApp  ]  ← botão
 └──────────────────────────────┘
```

### Passo 3.3 — Publique
1. Clique em **"Share"** (compartilhar), no canto superior.
2. Ative a opção **"Publish"** (publicar).
3. Clique em **"Copy link"** (copiar link). Pronto, sua página tem endereço na internet! 🎉

---

# PARTE 4 📣 — Divulgue sua página

Agora que você tem o link, espalhe por aí:

1. **WhatsApp Status**: cole o link com uma frase chamativa.
2. **Instagram**: cole o link na **bio** do perfil.
3. **Grupos de bairro / Facebook**: compartilhe com uma foto.
4. **QR Code**: no Canva, busque "QR Code", cole seu link, baixe e imprima! 🖨️

> 💡 **Dica de ouro:** teste o link você mesmo antes de divulgar — abra no navegador em modo anônimo (ou no celular de alguém) e veja se tudo aparece certinho.

## 🆘 Deu ruim? Problemas comuns

| Problema | Solução simples |
|----------|-----------------|
| A imagem não aparece | Ela é muito pesada. Baixe do Canva em tamanho menor (JPG). |
| O botão não abre o WhatsApp | Confira se o link começa com `https://wa.me/55` e tem o DDD. |
| Errei um texto depois de publicar | Abra o editor de novo, corrija e clique em "Publish Changes". |
| Esqueci como entrar no editor | Entre em `carrd.co` → "Dashboard" → clique no seu site. |
| A página fica estranha no celular | No Carrd, clique no ícone de **celular** (topo do editor) pra pré-visualizar. |
